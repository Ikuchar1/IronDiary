# IronDiary - Product Overview

IronDiary is a gym progress tracker that allows users to log and review their fitness activity over time.

## Core Features

- User registration and authentication (JWT-based)
- Workout log tracking (Push/Pull/Legs with optional notes and photos)
- Body weight logging
- Rest day logging
- Per-user data isolation — all records are scoped to the authenticated user

## Users

Single user type. Users register with email/password and access their own private fitness data after login.
